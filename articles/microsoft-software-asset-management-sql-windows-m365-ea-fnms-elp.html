Windows Server Licensing

Practitioner Notes

Windows Server practitioner answer should include minimums and virtualization rights.

Windows Server is licensed by physical cores. Standard and Datacenter require licensing all physical cores on the server, with minimum 16 cores per server and 8 cores per processor. Standard grants rights for two OSEs/VMs per full license of the host; Datacenter grants unlimited OSEs on the fully licensed host.

ScenarioCalculationResultConsultant Note
2-socket host, 10 cores each, Windows Server Standard, 4 VMsPhysical cores = 20. Need 20 core licenses for first 2 VMs, another 20 for next 2 VMs.40 core licenses required.Standard stacks; Datacenter may be cheaper in dense virtualization.
2-socket host, 24 cores each, Windows Server Datacenter, 80 VMsPhysical cores = 48. License 48 cores once.Unlimited Windows Server VMs on that host.Validate all host cores covered and SA/AHB if cloud benefit claimed.
Small 8-core serverMinimum applies: 16 core licenses.16 required.Minimums create exposure even on small hardware.

SQL Server Licensing

Practitioner Notes

Strong line: “SQL ELP accuracy depends on edition and environment classification before the formula.”

SQL Server is commonly reconciled by edition and metric. Core licensing must detect edition, physical vs VM licensing model, assigned cores, minimum four cores per VM, and Software Assurance benefits such as license mobility or passive failover rights.

ExampleInputsFormulaPosition
SQL Enterprise VM8 vCPU, Enterprise Core, entitled 12 coresRequired = MAX(4,8)=8Surplus 4 cores
SQL Standard small VM2 vCPU, Standard Core, entitled 2 coresRequired = MAX(4,2)=4Short 2 cores due to minimum
Server + CAL1 SQL Standard server, 120 users, 100 SQL CALsServer license + CALs for users/devices20 CAL shortfall
SQL Edition Mismatch

A SQL Enterprise install discovered as Standard in inventory, or a Developer edition used in production, can swing the ELP materially. Validate edition through SQL queries, installer evidence, and application owner confirmation.

SQL detection request
Please provide SQL Server inventory with server, instance, edition, version, environment, assigned vCPU/physical cores, cluster role, passive/active status, and output from SELECT @@VERSION plus SERVERPROPERTY('Edition').

Microsoft 365 / Office Licensing

Practitioner Notes

User subscription optimization is a quick win: compliance plus savings.

M365 ELP compares assigned licenses and service usage against entitlement pools. It also identifies optimization: inactive users, duplicate SKUs, over-assigned E5 features, shared mailboxes, disabled accounts, and license plans assigned outside job need.

Enterprise Agreement / True-Up

Practitioner Notes

Microsoft SAM reviews often test whether you know SAM engagement vs annual true-up rhythm.

EA true-up is the annual mechanism for reporting growth in enterprise products, qualified users/devices, and additional products. A good ELP reconciles baseline, adds, reductions where allowed, transitions, online services, and anniversary dates.

EA ElementWhat to ValidateTrue-Up Risk
Qualified devices/usersCurrent count vs baselineGrowth not reported.
Enterprise productsWindows, Office/M365, EMS suitesMixed SKU transitions missed.
Additional productsSQL, Windows Server, Visio, ProjectAd hoc deployments outside procurement.
Online servicesAssigned subscriptionsCSP/EA double-buy or unlicensed usage.

Manual ELP Creation (Step-by-Step)

Practitioner Notes

Mirror IBM: entitlement, consumption, metric math, assumptions, executive view.

  1. Define scope: program (EA/MCA/CSP), products, legal entities, datacenters, cloud tenants, and reporting date.
  2. Collect hardware and virtualization data for Windows Server and SQL.
  3. Collect software deployment: SCCM/Intune, SQL discovery, installed applications, server roles.
  4. Collect users/devices: Entra ID, AD, HR, M365 admin, CAL population.
  5. Collect entitlements: MLS, VLSC, EA portal, CSP invoices, reseller records, SA status.
  6. Calculate per product metric, including minimums and virtualization rights.
  7. Document assumptions, evidence gaps, and optimization opportunities.
  8. Present executive RAG plus detailed reconciliation workbook.

Practitioner Q&A

Practitioner Notes

Use numbers: core minimums, VM rights, user counts, true-up deltas.

How do you calculate Windows Server Standard in virtualization?

License all physical cores on the host with minimums. Standard grants two OSEs per fully licensed host; additional VMs require stacking another full set of core licenses.

Why it matters: Whether you know virtualization rights.

What is the biggest SQL Server ELP trap?

Edition and environment classification. SQL Enterprise vs Standard, Developer in production, passive nodes, and VM core minimums can all change the position.

Why it matters: Whether you validate discovery.

How do you handle M365 optimization?

Compare assigned licenses to active users, last sign-in, service-plan usage, HR status, and business role, then reclaim or downgrade unused or overpowered SKUs.

Why it matters: Whether you combine compliance and savings.

SAM engagement vs audit?

A SAM engagement may be positioned as advisory, but the data can still drive commercial pressure. I control scope, evidence, and assumptions like an audit.

Why it matters: Whether you understand vendor dynamics.
